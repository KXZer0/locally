# Historical material

This directory preserves superseded design and implementation records. They are
useful for understanding earlier decisions, but they are not operating
instructions for the current project.

For current setup and use, start with [the repository README](../../README.md).
The active product is a headless local API with an optional terminal chat
client; the browser UI described in the files below was retired.

- The root of this directory holds prior API, model, UI, and planning records.
- `ui-tooling/` contains the browser measurement scripts and demo captures used
  for the retired web interface.

Keep new user-facing documentation outside this directory. Move a document here
only when it has been replaced and is being retained solely as a record.
