# Web page -> Markdown for the Util reader's URL input.
#
# Scrapling is the obvious library here and was tried first. It is not used:
# `scrapling.fetchers` cannot be imported without Playwright's Python package,
# which measured **223 MB** of browser automation (playwright + patchright) for
# a path that never launches a browser — against **1.1 MB** for these two doing
# the same job. This project self-hosts its own fonts so it works on a plane;
# 223 MB of unreachable code is not a rounding error. What Scrapling would add
# over this is anti-bot bypass, and that needs the browsers anyway.
#
# curl_cffi carries the useful half: a real Chrome TLS/JA3 fingerprint, so
# pages that refuse python-requests still answer. markdownify (with the
# BeautifulSoup it already depends on) does the conversion, after locally
# strips the nav/header/footer/script furniture — which is the whole point,
# since that clutter is most of the token cost on an 8k NPU window.
#
# Optional: without them the server still starts and /v1/util/read still reads
# images and documents. Only a URL errors, naming this command.
curl_cffi>=0.16.0
markdownify>=1.2.0
